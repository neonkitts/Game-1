# Проверка опубликованного прототипа

Проверены файлы GitHub 9 октября 2026 года. Это статический обзор исходников и YAML сцены; Unity здесь не запускалась.

## 1. Согласовать файл и класс движения

Файл `Assets/Script 1/Player1/Playermoment.cs` объявляет класс `PlayerMovement`. В `SampleScene.unity` компонент сохраняет идентификатор `Script_1.Player1.Playermoment`. Эти имена расходятся.

В Unity переименовать файл в `PlayerMovement.cs`, сохранив его `.meta` и GUID. После компиляции проверить компонент на объекте Player: если он отображается как Missing Script, подключить корректный компонент и заново назначить скорость и Animator. Сохранить сцену.

## 2. Подключить пчелу и установщик

В опубликованной `SampleScene.unity` найдена ссылка на скрипт игрока, но не найдены ссылки на GUID скриптов `EnemyBeeMovement` и `PlayerInstaller`.

Для демонстрации преследования в основной сцене нужны:
- объект игрока с `PlayerMovement` и назначенным Animator;
- объект пчелы с `EnemyBeeMovement` и положительной скоростью;
- `SceneContext` Zenject;
- `PlayerInstaller`, назначенный в списке Mono Installers у SceneContext, со ссылкой на игрока.

Перед загрузкой в GitHub проверить, что сохранена именно эта сцена. Папки `_Recovery` содержат резервные сцены; они не являются основной точкой запуска.

## 3. Проверить Animator

Скрипт отправляет три float-параметра: `Horizontal`, `Vertical`, `Speed`. Они должны существовать в контроллере, назначенном фактическому Animator игрока. В контроллере `Assets/Animation 1/Player 1/Player Controler.controller` эти параметры есть.

## 4. Выполнить ручную проверку

- WASD и стрелки двигают персонажа в нужном направлении.
- Диагональное движение не быстрее горизонтального.
- При отпускании клавиш персонаж останавливается, анимация переключается.
- Пчела следует за игроком, Console не содержит NullReferenceException или ошибок Zenject.
- Проверка повторяется после выхода из Play Mode и повторного запуска.

В опубликованном `EnemyBeeMovement` есть движение к игроку, но нет обработки контакта и урона. Для следующего этапа добавить урон и задержку между атаками, затем отдельно проверить их.

## 5. Подготовить материалы для отклика

Добавить скриншот и 20–30-секундную запись своей сцены. Указать источник учебных материалов и спрайтов, когда он известен. После проверки собрать игру и приложить полный архив сборки к GitHub Release.

В рамках оформления изменена только документация. Работа механик и исправление перечисленных проблем пока не подтверждены запуском.
