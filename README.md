# Game 1 — движение игрока и преследующий враг

Учебный **2D-прототип на Unity и C#**. В проекте я практикую движение персонажа, переключение анимаций и поведение врага-пчелы, который движется к игроку.

**Статус:** прототип в разработке. Скрипты механик находятся в репозитории; опубликованная сцена ещё требует синхронизации с ними. Готовая сборка и запись игрового процесса пока не добавлены.

[Подробное описание механик и моего вклада](docs/MECHANICS.md).

## Моя практика

В этом проекте я работаю над ходьбой персонажа и преследованием игрока врагом. Основные скрипты моей практики находятся в папке [`Assets/Script 1`](Assets/Script%201). В репозитории также есть отдельная папка [`Assets/урок 1`](Assets/%D1%83%D1%80%D0%BE%D0%BA%201) с учебными материалами и более сложными системами; они не перечисляются здесь как мой самостоятельный результат.

## Механики в коде

- **Движение по двум осям:** ввод через `Horizontal` и `Vertical`, нормализация направления для одинаковой скорости по диагонали, учёт `Time.deltaTime`.
- **Анимация персонажа:** передача параметров `Horizontal`, `Vertical` и `Speed` в Animator.
- **Преследование игрока:** пчела вычисляет направление к персонажу и движется к нему с заданной скоростью.
- **Связь игрока и врага через Zenject:** `PlayerInstaller` регистрирует игрока, `EnemyBeeMovement` получает ссылку через `[Inject]`.

Преследование — текущая основа поведения врага. Нанесение урона, здоровье и интервал атаки в `EnemyBeeMovement` пока не реализованы. Перемещение выполняется через `Transform`; физические столкновения этим кодом не обрабатываются.

## Открытие проекта

1. Скачайте репозиторий через **Code → Download ZIP** или клонируйте:
   ```bash
   git clone https://github.com/neonkitts/Game-1.git
   ```
2. В Unity Hub выберите **Add → Add project from disk** и укажите папку с `Assets`, `Packages` и `ProjectSettings`.
3. Используйте Unity **6000.4.7f1** — версию из [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt).
4. Дождитесь импорта и откройте `Assets/Scenes/SampleScene.unity`.

Код использует старый Input Manager. В проекте включён режим **Both**. Оси `Horizontal` и `Vertical` обычно соответствуют WASD и стрелкам; их настройки можно проверить в **Project Settings → Input Manager**.

**Перед запуском:** опубликованная сцена пока не содержит подключённых `EnemyBeeMovement` и `PlayerInstaller`. Также нужно согласовать имя файла движения с классом. Порядок проверки описан в [заметках по проекту](docs/PROJECT_REVIEW.md). Запуск в Unity после оформления репозитория ещё не проверен.
